# LifeForgeRPG
Convierte tu vida en un RPG con misiones, niveles, XP, aliados, enemigos y un HUD completo.

LifeForgeRPG transforma tus hábitos en un videojuego: cada día es una misión, cada semana un reto, cada mes una temporada. Incluye un sistema completo de XP, niveles, skill tree, facciones, inventario, jefes finales y lore.

---

## 🎮 Características principales
- HUD estilo videojuego
- Misiones diarias, semanales y de temporada
- Sistema de XP y niveles
- Árbol de habilidades (skill tree)
- Aliados, enemigos y jefes finales
- Inventario y equipamiento
- Facciones y clases
- Lore completo del mundo
- Eventos especiales mensuales

---

## 📱 Objetivo
Construir una app Android (APK) que permita gestionar hábitos como un RPG.

---

## 🛠️ Tecnologías sugeridas
- Android Studio
- Kotlin + Jetpack Compose
- Room (base de datos local)
- ViewModel + LiveData
- DataStore
- Material Design 3
